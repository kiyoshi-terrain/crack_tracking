# 再撮影時のDIC位置合わせ：v33

2026-09-17。v32の専用基準枠に、広域の初期探索と品質ゲートを追加した。
公開版の更新・実iPhoneでの動作確認はこの記録には含まない。

## 変更の目的と範囲

標点間距離をT1–T2=186mmで正規化する方式は、一様倍率には対応するが、
撮影角度が変わると方向・位置による縮尺差が残る。室内試験でも撮り直し前後に差が生じた。
DIC比較側で指定した基準領域の模様を探し、射影位置合わせ後に品質を検査する。
標点間距離の表に射影補正を追加したものではない。黒丸やカードを位置合わせに使って
測りたい動きを消すことを避け、今回の実写検証ではカードの外の壁を基準にした。

- 初期探索：長辺320px以下へ縮小し、局所平均を引いた模様を使って枠全体の位置を探索。
  一様な面や明暗勾配だけの高相関を採用しない。枠全体が画像内に入る候補に限る。
- 初期採用：相関0.65以上、最良候補から小画像4px超離れた候補との差0.04以上。
  初期探索は並進であり、大きな回転・変形を必ず解けるものではない。
- 粗い／精密推定：格子位置によって約2/3をフィット、約1/3を検査に割り当てる。
  検査点はその段階の最終変換フィットに入れず、外れ値除去もしない。
  別写真・統計的に独立したノイズで検証しているという意味ではない。
- 品質ゲート：採用12点以上、検査6点以上。点群の短軸方向の標準偏差40px以上
  （基準画像換算）を要求し、点の偏りを拒否する。
- 検査残差の90%点：粗い段階は小画像2px以下、精密段階は基準画像1px以下。
  いずれも暫定の画像品質条件であり、mm精度や基準部材の不動を保証しない。
- 不合格フレームは変位の集計から除外。合格2枚未満なら変化量を確定しない。
  表示の使用枚数も実際の合格数に合わせる。
- UI：採用点は緑、検査点は紫。初期相関・候補差・精密検査の残差・棄却理由を表示。

枠外への外挿、レンズ歪み、奥行き差、基準領域自体の動きは、このゲートだけでは解決しない。
検査点の残差を、そのまま標点の距離精度やき裂開口の精度として扱わない。

## 実写検証

利用者提供の3セット（各10枚、4032×3024、35mm換算120mmのJPEG）を使用。
原画像と撮影場所の写真はリポジトリへ含めていない。
基準はIMG_3002.JPG。専用基準枠は元画像座標 x=950, y=450, 幅350, 高さ1100。
カードの左側の壁を選んだ。黒丸・カードはこの枠に含めていない。

subsetHalf=15、step=40、coarseScale=4、精密検査の許容90%残差=1px。
下の任意スクリプトでは精密探索も基準枠に限定し、枠外の変位評価は行わない。

| 対象 | 枚数 | 初期相関の範囲 | 結果 |
|---|---:|---:|---|
| 最初のセットの残り IMG_3003–3011 | 9 | 0.651–0.728 | 全枚で精密対応点が不足。基準域内216探索点中、対応成立は1–2点 |
| 一脚で撮り直した IMG_3014–3023 | 10 | 0.383–0.443 | 全枚で初期照合の相関不足 |
| 見上げ約14° IMG_3024–3033 | 10 | 0.342–0.354 | 全枚で初期照合の相関不足 |

**29枚とも不成立。実写で補正後の距離誤差が減ったとは確認できていない。**
これは上記の壁領域と条件での結果であり、全ての基準領域・全てのDIC方式が不可能という結論ではない。
同じ固定状態でも画素ごとの模様の照合が足りず、構図のずれだけの問題ではなかった。
明暗勾配を含む探索では、別の壁領域にも0.97程度の高相関が出たため、局所模様と候補差の検査を採用した。

## 再現

数値・合成画像のテスト：

```sh
node web/test/run.mjs
```

元画像を手元に置いた実写検証（任意依存 @napi-rs/canvas が必要）：

```sh
CRACK_UI_DEPS=/path/to/dependencies node web/test/real-registration.mjs \
  /path/to/IMG_3002.JPG 950,450,350,1100 \
  /path/to/IMG_3003.JPG /path/to/IMG_3014.JPG /path/to/IMG_3024.JPG
```

基準以外の29枚を全て引数に渡して実行できる。出力はファイル名と診断JSONのみ。
同じROIで実装結果を再現するためのスクリプトで、良いROIを自動選定するものではない。

## 合成検証と残る作業

全体の自動テストは369件成功、0件失敗。簡易DOM・模擬IndexedDBによる基準枠の保存・再読込み、
比較の成立／不成立、採用点描画、結果破棄も成功した。実ブラウザーの試験を代替するものではない。

- 画面幅の37.5%の並進を初期探索で復元。
- 一様面、明暗勾配、反復模様、不正なROI、検査点不足、一直線への点の偏りを拒否。
- フィット点が正しくても検査点がずれれば不合格。
- 0.4°回転＋0.75pxの開口を与えた合成画像で、品質ゲート後も開口約0.7496pxを保持。
- 不合格写真を除外し、合格1枚では確定しない。

実写で安定した対応を得られる基準模様の確保と、独立に既知変位を与える検証が必要。
合成結果を現地の精度保証に使わない。実Safari・カメラ・PWA更新は未検証。
