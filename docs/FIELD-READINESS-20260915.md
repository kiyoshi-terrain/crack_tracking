## 1. 現在できることと、修正したこと

| 項目 | v32の処理 | 限界 |
|---|---|---|
| ターゲット | 黒丸の中心を検出し、対応した中心間距離を比較 | ターゲットによる射影位置合わせは未実装。き裂幅そのものではない |
| 現地ID | 検出図を見て人がIDと部材IDを入力 | 印字IDの自動読取りではない。毎写真セットの照合が必要 |
| 縮尺 | 同一部材と指定した2点の実測中心間距離を使い、写真ごとに距離比を計算 | 一様倍率変動への対応。斜め撮影・奥行き差・基準対自体の動きは解決しない |
| 履歴 | 現地IDの対・縮尺対・既知長が異なる記録の混入を拒否 | 同じIDを別の物に付けた誤りや、誤対応は人が確認する |
| DIC開口 | 基準画像に保存した線の両側の相対変位を算出 | 安定域の選び方と画像の模様・姿勢に依存 |
| DIC位置合わせ | 粗い位置合わせ・精密な再推定・視差モデルの推定に同じ安定域を反映 | 指定領域が本当に相互不動かどうかはソフトでは判定しない |
| DIC基準枠 | 比較シートの専用キャンバスで青枠を描き、保存済み基準に保持 | 橙の解析枠と別設定。旧解析枠は自動転用しない |
| 対応点の確認 | 写真ごとに粗い／精密な採用点・外れ値・対応不成立点を重ね、点数と失敗理由を表示 | 点数や分布だけで不動や実写精度は保証できない |
| DICのmm換算 | 保存した基準日のGSD、または基準画像用の明示入力を使う | 既知寸法や撮影幾何で基準日の換算を確かめる必要がある |
| 設定変更 | ID・縮尺の変更で値を再計算。写真変更で過去の計測値を消去 | 実iPhoneでの操作確認は別途必要 |

ターゲットの縮尺対自身は定数に正規化されるため、変位の記録候補には出さない。
記録用の不確かさは連写の繰返しSEに固定床を合成した値であり、総合的な測定精度ではない。
床の0.02pxは既存方式に合わせた仮定で、20mm黒丸を現地条件で実測して確かめた値ではない。
標点方式とDICが一致しても、両方に共通する誤差や接着の健全性を保証しない。

## 2. ターゲットの役割と暫定配置

「不動点」はターゲットの形で決まらない。何に取り付け、何を基準に測るかで決まる。

| 役割 | 設置する場所 | 記録する内容 |
|---|---|---|
| 動きを測る点 | 動きを知りたい左右それぞれの部材。部材の動きに追従するよう固定 | 現地ID、部材ID、写真上の位置 |
| 縮尺用の対 | 相互に動かないと確認できる同一の石・板の上の2点 | 両方の現地IDと実測中心間距離 |
| DICの基準領域 | 位置合わせの基準にする、相互に変形しない同一面の模様のある領域 | 基準画像上の専用青枠（内側を使用） |

左右各2点を検討の出発点にできるが、必要数・位置は全景と個々の石の境界を見て決める。
「左側全体」「右側全体」がそれぞれ一体で動くとは限らない。違う石を同一部材扱いしない。
縮尺対をき裂の左右に分けて置くと、測りたい変位を縮尺として吸収するおそれがある。
片側を地盤に対して不動と確認できなくても、左右の相対変化を測ることはできる。

中心間距離の変化は、その対を結ぶ方向の動きに主に感度がある。
き裂の開きを見たい対は、可能ならき裂にほぼ直交する方向に配置する。
斜めの対やせん断を伴う動きでは、距離変化をそのまま法線方向の開口と呼ばない。

黒丸を全撮影位置から遮らずに撮れ、カードが反ったり風で揺れたりしない取付けを選ぶ。
ターゲット自体のずれは部材の動きと区別できない。
大谷石への固定方法は、石の状態、採用するアンカー／接着剤、施工温度、硬化時間を
確認して決める。写真だけから穴径・深さ・硬化時間・耐久年数を指定しない。

## 5. 設置前に行う実写試験

倍率は固定値を今ここで決めず、実際の20mm黒丸が何pxに写り、何枚で安定して検出できるかで決める。
水平18mを距離欄へそのまま入れない。高さ差・斜め撮影を含む幾何を確認する。
縮尺は撮影対象と対応する実測寸法で確かめる。表示ズーム値だけでレンズや保存画素数を決めつけない。

1. 実物ターゲットを動かない試験面に仮固定し、候補距離・倍率ごとに元画像を10枚程度撮る。
   各セットで撮影方法を揃え、機種、倍率表示、画像寸法、EXIF、距離、光、支持方法を記録する。
2. 無変位のまま独立した撮影セットを複数回作り、距離の再現性と誤検出を確認する。
3. 縮尺対を動かさず、計測側だけ独立に確認できる既知量だけ動かして別セットを撮る。
   目標とする最小変化を十分細かく確認できる治具・測定器が必要。治具はまだ指定していない。
4. 無変位のまま想定する再訪の位置・向きの違いを与え、見かけの変位を確認する。
   撮影位置を変える試験と、部材を動かす試験は分けて評価する。
5. iPhone Safariで読込み・保存・再読込み・2時期比較・履歴JSON出力を通し、端末上の版番号を確認する。
   実写の結果と必要な最小変化から、使う倍率・支持方法・許容する撮り直し条件を決める。

不足している情報は、現地で確認した設置可能位置、必要な最小変化、固定部品候補、実物ターゲットの試写。
これらが揃うまでは、現地配置や0.1mm検出を確定事項として扱わない。
