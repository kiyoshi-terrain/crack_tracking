レンズ校正シート

レンズの歪みを実測するための格子です。7×5 の 35 点。 A4 に原寸で印刷して使います。

なぜ要るのか

2時期を比べるとき、前回と立ち位置が違うと、レンズの歪みが偽の変位として残ります。 ホモグラフィは直線を直線に写すので、放射歪みを表現できないためです。 合成検証では、歪み 2% ＋ 姿勢差が中程度のとき 71 セル中 44 セルが偽陽性になり、 校正を入れると 3 セル（歪みが無い場合と同じ水準）まで戻りました。

同じ立ち位置に戻れているなら校正は要りません。再訪ガイドどおりに戻れた場合は、 歪み 2% でも偽陽性は 0 でした。校正は「戻り切れなかったときの保険」です。

手順

  1. このページを A4 原寸で印刷する（拡大縮小なし）
  2. 反りのない板か壁に、たわまないよう平らに貼る
  3. 校正したいレンズ（0.5× / 1× / 5×）に切り替える
  4. 用紙が画面いっぱいに写る距離から、正対・正立で撮る。 隅の点まで入れること（歪みは隅がいちばん大きい）
  5. 少し傾けた向きでも 2〜3 枚撮ると安定する
  6. アプリのスケールシートから読み込む

気をつけること

  • 用紙は平らに。たわみは歪みと区別がつきません
  • 正立で撮る。90° 回すと格子の行を判別できず、アプリが読み込みを断ります
  • ピントを合わせる。ボケると重心がずれます
  • 点は暗い円として検出します。強い反射や影が乗らない照明で
  • レンズごとに校正が要ります（超広角・広角・望遠は別のレンズです）
